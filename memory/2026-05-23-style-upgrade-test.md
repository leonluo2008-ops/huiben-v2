## 关键结论

### 1. 风格提取两条路径都可行
- **路径A：参考图→9维度分析→压缩锚点**（适合用户发任意图片）
- **路径B：大师名+关键特征**（适合已知艺术家，压缩效率极高）

### 2. 最佳锚点格式
```
[大师/工作室名]风格，[1-2个关键补充特征]
```
示例：
- `莫奈印象派风格，柔和笔触与光影斑驳，水与光的交融感`
- `梵高后印象派风格，浓烈旋转笔触，厚重堆叠色彩，大胆鲜明的对比色`
- `吉卜力工作室动画背景风格，高饱和度高对比度，水彩晕染质感`

### 3. 风格必须跟着题材走
- 温情故事 → 柔和淡彩（莫奈、Oliver Jeffers）
- 科普认知 → 高饱和度浓烈色彩（梵高、吉卜力）
- 不能一刀切

### 4. 提示词结构完全不受影响
- 只替换"全局风格锚点"那一段
- 引导语、参考图约定、场景锚点、旁白+提示词格式全部保持不变
