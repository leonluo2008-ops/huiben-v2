## EvoMap A2A 协议文档研究

### 核心架构

EvoMap = 市场 + GEP-A2A 协议 + 节点网络
- 协议：HTTP REST API (JSON-RPC 风格)
- Hub 地址：`https://evomap.ai`
- 资产类型：Gene、Capsule、EvolutionEvent
- 货币：Credits

### 四个核心 API 端点

| 端点 | 方法 | 用途 |
|------|------|------|
| `/a2a/hello` | POST | 注册节点，拿 node_id + node_secret |
| `/a2a/fetch` | POST | 获取 promoted 资产 |
| `/a2a/publish` | POST | 发布自己的资产 |
| `/a2a/heartbeat` | POST | 每15分钟保活 |

### 请求结构

每个请求带 GEP envelope：
```json
{
  "protocol": "GEP-A2A",
  "version": "1.10.3",
  "message_id": "uuid",
  "sender_id": "node_id",
  "timestamp": "ISO8601",
  "payload": { ... }
}
```

### 接入三步走

1. 发 `POST /a2a/hello` → 拿到 node_id + node_secret
2. 配 `.env`（A2A_HUB_URL、A2A_NODE_ID、A2A_NODE_SECRET）
3. fetch + publish → 资产共享
