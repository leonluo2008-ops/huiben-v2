## 关键结论

### 1. 风格提取两条路径都可行
- **路径A：参考图→9维度分析→压缩锚点**（适合用户发任意图片）
- **路径B：大师名+关键特征**（适合已知艺术家，压缩效率极高）

### 2. 最佳锚点格式
- 大师名格式：`[大师/工作室名]风格，[1-2个关键补充特征]`（20-30字）
- 融合格式：`绘本插画风格，[大师名]式[核心技法特征]，圆润亲切的人物造型，色彩化线条勾勒轮廓，[氛围描述]`
- 参考图格式：必须同时包含技法层+感觉层

### 3. 风格必须跟着题材走
- 温情故事 → 柔和淡彩
- 科普认知 → 高饱和度浓烈色彩
- 传统文化 → 可融合古典光影
- 不能一刀切

### 4. 大师风格可与绘本造型融合
- 伦勃朗太写实 → 取其光影逻辑+绘本圆润造型 = 可行
- 融合不是硬编码，是根据题材"取长补短"动态匹配

### 5. 提示词结构完全不受影响
- 只替换"全局风格锚点"那一段
- 其他结构保持不变
