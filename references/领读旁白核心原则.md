# 领读旁白核心原则：目标词必须出现

> 领读绘本的核心功能是**教孩子认读目标单词**。每一行旁白都必须让目标词在页面上出现——不是藏在句子里，是**显眼的、可指数的**。

## 错误模式

❌ 当前测试暴露的问题：
```
| 1 | A lion | 一只狮子 |
| 2 | A big lion | 一只大狮子 |
| 3 | The big lion runs | 大狮子在跑 |
```

**问题**：目标词 LION 消失在句子中，小孩子翻书时看不到"LION"，失去了领读功能。

## 正确模式

✅ 目标词必须单独成行或作为页面视觉焦点：

```
| 1 | LION | 狮子 |
| 2 | L-I-O-N | 拼读 |
| 3 | A LION | 一只狮子 |
| 4 | I see LION | 我看见狮子 |
```

**关键**：
- L1 必须是目标词本身（建立"这个词=这个物"的第一印象）
- 后续每行旁白中，目标词必须大写并可辨认
- 目标词在每个句子中都要出现（全书至少8次）

## 为什么这个原则必须严格遵守

领读绘本 vs 故事绘本的本质区别：

| 维度 | 故事模式 | 领读模式 |
|------|---------|---------|
| 目的 | 讲完整故事 | 教一个单词 |
| 核心资产 | 旁白的叙事弧线 | 目标词的复现频率 |
| 页面文字 | 可以只是旁白 | **必须包含目标词** |

**没有目标词在页面出现 = 领读绘本失效。**

## 验证方法

每行旁白产出前自检：
- [ ] 本行英文是否包含目标词？
- [ ] 目标词是否大写？
- [ ] 如果一行有两个词都认识，这个组合是否正确？
- [ ] 目标词在句首/句中/句尾时的视觉呈现是否够醒目？

## 参考：各页面类型的目标词出现方式

| 页码 | 页面类型 | 目标词出现方式 |
|------|---------|---------------|
| 封面 | 认知页 | 目标词超大显示（占据画面1/4-1/3） |
| P1 | 字母拆解页 | 字母逐个分色展示（辅音红/元音蓝） |
| P2 | 拼读示范页 | 拼读过程（每个音节可读） |
| P3-P(n-1) | 语境页 | 目标词在句中高亮（文字即图形） |
| Pn | 互动练习页 | 描红、连线、圈选目标词 |
