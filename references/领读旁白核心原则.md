# 领读旁白核心原则：中文翻译 + 英文领读并列结构

> 领读绘本的核心功能是**教孩子跟读目标单词**。中文旁白提供翻译，英文旁白提供跟读范本，两者并列存在，不混合。

## 旁白结构

| 旁白 | 内容 | 作用 |
|-----|------|------|
| 英文旁白 | 完整原句（含目标词） | 供孩子跟读 |
| 中文旁白 | 完整中文翻译句 + 英文核心短语领读 | 供理解 + 领读练习 |

**中文旁白格式：`[完整中文翻译] [英文核心短语]`**
- 中文句 = 准确翻译（让孩子理解意思）
- 英文短语 = 目标词/短语（孩子跟读练习）
- 两者用空格分开，英文在前时如"go 快！"，中文在前时如"快走，go slow!"

## 错误模式

❌ 硬把目标词塞进中文句子里，破坏中文流畅性：
```
| Go slow! | 慢慢 go！ | ← 中英混合，中文被破坏 |
| I go. | 我 go。 | ← "我 go"不成句 |
```

❌ 只写中文翻译，丢失目标词：
```
| Go slow! | 慢慢走！ | ← 目标词丢失，失去领读功能 |
```

## 正确模式

✅ 中文旁白 = 完整中文句 + 英文核心短语并列：

| 英文旁白 | 中文旁白 |
|---------|---------|
| go slow! | 慢慢走！go slow! |
| Go fast! | 快快走！go fast! |
| I go. | 我走，I go. |
| We go! | 我们走，We go! |

**关键**：
- 中文是完整的翻译句
- 英文目标短语独立出现，不破坏中文流畅
- 两者在同一行并列，供孩子跟读

## 为什么这个原则必须严格遵守

领读绘本 vs 故事绘本的本质区别：

| 维度 | 故事模式 | 领读模式 |
|------|---------|---------|
| 目的 | 讲完整故事 | 教孩子跟读 |
| 核心资产 | 旁白的叙事弧线 | 目标词的复现频率 |
| 旁白结构 | 双语同句（中文叙事+英文目标） | 中文翻译 + 英文领读并列 |

**中文旁白丢失目标词 = 领读功能失效。**
**中文旁白硬塞目标词 = 失去绘本自然感。**

## 验证方法

每行旁白产出前自检：
- [ ] 英文旁白是否包含目标词（完整原句）？
- [ ] 中文旁白是否包含完整中文翻译句？
- [ ] 中文旁白是否包含英文目标短语（与中文用空格/逗号分开）？
- [ ] 英文目标短语是否完整（go slow! 而非仅 go）？
- [ ] L1行目标词是否全大写？正文行目标词大小写与英文原文一致？
- [ ] 目标词为词组时（如 go slow / I go）是否保持完整未拆分？
- [ ] 中文翻译是否准确（完整句，不破坏中文流畅）？
