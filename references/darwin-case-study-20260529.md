## 问题一：简介偏离核心词

### 现场回放

用户反馈："简介都不好，需要重写，要围绕核心词来写"

**第一次输出的简介：**

```
1. 蓝色的 plane 在天上飞，crane 也在飞……它们都押 ANE！到处都是 plane！
2. 我能看，能指，能喊——plane！plane！plane！ANE 我都认识！
3. 蓝色的 plane、白色的 crane、长长的 lane……ANE 家族的宝贝可真多！
```

**问题分析：**

三条简介的重心都偏向了词族展示（ANE家族、crane、lane），plane 反而成了配角。简介变成了"词族广告"，不像给孩子听的第一句话。

**根因：**

skill 缺少"简介必须以目标词为绝对主角"的约束。词族扩展词（crane、lane、cane等）在简介中的角色没有约束，容易喧宾夺主。

## 问题二：叠词与目标年龄不匹配

### 现场回放

用户反馈："飞得高高，这种词汇不要出现，过于低幼"

**原始旁白第4行：**

```
英文：A blue plane flies high.
中文：蓝色的飞机飞得高高，a blue plane flies high
```

**修改后：**

```
中文：蓝色的飞机飞得很高，a blue plane flies high
```

**问题分析：**

叠词"高高"是典型的低幼/婴语表达。目标年龄是4-6岁，这个年龄段的孩子已经不需要叠词来辅助理解，用"得很高"更自然、更适龄。

**根因：**

skill 的叠词规则只区分了"正向叠词"和"反向叠词"的自然度，完全没有考虑目标年龄。"允许"列表里的叠词对3岁合适，对5-6岁就过于低幼。

## 修复记录

### 修复1：简介核心约束（目标词必须是绝对主角）

**修复位置：** SKILL.md「简介创作要求」章节

**修复内容：** 在简介创作要求前新增「⚠️ 简介核心约束：目标词必须是绝对主角」规则，含三种错误类型+正确示例对照表：

| 错误类型 | 错误示例 | 正确示例 |
|---------|---------|---------|
| 词族喧宾夺主 | "plane、crane、lane……ANE 家族的宝贝可真多！" | "蓝色的 plane 在天上飞，到处都是 plane！" |
| 目标词变配角 | "它们都押 ANE！crane 在飞，lane 在延伸……" | "plane 怎么学？天上飞的就是 plane！" |
| 目标词缺失 | "ANE 家族有哪些词？crane、lane、cane……" | "找一找，plane 在哪里？" |

同时更新自检清单第3项，添加「目标词是否为绝对主角？词族词是否喧宾夺主？」检查项。

### 修复2：叠词规则按年龄分层

**修复位置：** SKILL.md「语境重复页设计规则」章节

**修复前：**

```
- 中文叠词自然度：
  - 允许：高高、大大、长长、远远、快快、慢慢（正向夸张）
  - 禁止：低低、小小、短短（反向叠词不自然）
  - 不确定时改用其他表达，不套格式
```

**修复后：**

```
- 中文叠词使用（按年龄分层）：
  - 3岁：允许叠词（飞得高高、走得慢慢）
  - 4岁：少量叠词，优先用"得很+形容词"（飞得很高、走得很快）
  - 5-6岁：避免叠词，用完整口语表达（飞得很高、跑得很快、走得很慢）
  - 核心原则：年龄越大语言越接近自然口语，叠词是低幼辅助工具，5岁以上旁白禁 用"高高""大大"等婴语叠词
  - 反向叠词：低低、小小、短短 等一律禁止，无论年龄
  - 不确定时改用"很+形容词"替代
```

同时更新自检清单第8项，添加年龄分层检查。

## 新发现：skill 规范正确不代表执行正确

### 子agent测试记录

| 测试 | skill遵循情况 | 结果 |
|------|-------------|------|
| prompt1「go」领读 | 子agent context 明确强调双语同现规则 | ✅ 通过 |
| prompt3「cat」领读 | 子agent context 未强调双语同现规则 | ❌ 失败，中文旁白丢失 cat |
| 修复后「cat」领读 | context 补充双语同现强制规则 | ✅ 通过 |

**结论：** skill 规范本身没有错，错误出在子 agent 执行时没有遵守。将双语同现检查从自检清单第5项移到第1项（加粗标记），可以提升执行遵守率。
