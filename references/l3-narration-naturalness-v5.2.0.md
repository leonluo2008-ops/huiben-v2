## 一、中文末尾英文仅核心词（v5.1.0 已锁定 · v5.2.0 强化）

- 每行旁白中文末尾的英文绑定统一压成**核心词**（如 olive tree 9 句 = `Olive Tree` / peach tree 9 句 = `Peach Tree`），不是完整短语。
- 中英标点默认加（封面 `!` / 认知无标点 / P3-Pn 按 `.` 或 `!` 对应）。
- 用户说"中文旁白后面的英文部分,只有核心词"或"兄弟,不要我再强调了" → 不要再每本问。

## 二、核心词贯穿中文（v5.2.0 新铁律 · 07-23 实测）

**每行中文都要让核心词做主语/被指向/出现在领读焦点位置**，不能游离在画面之外。

### ✅ 正模式（核心词贯穿）
- "这是一棵石榴树，Pomegranate Tree"（主语）
- "石榴树开红花啦，Pomegranate Tree"（主语）
- "蜜蜂飞向石榴树，Pomegranate Tree"（介宾指向）
- "石榴树冒出小青果，Pomegranate Tree"（主谓）
- "石榴树挂满红石榴，Pomegranate Tree"（主谓宾）
- "石榴树绿叶亮闪闪的，Pomegranate Tree"（领属结构）

### ❌ 反模式（核心词游离）
- "夏天来到石榴树上，Pomegranate Tree"（主语=夏天，石榴树只是地点状语）
- "蜜蜂飞进花丛里，Pomegranate Tree"（主语=蜜蜂花丛，没指石榴树）
- "裂叶晒着太阳，Hawthorn Tree"（主语=裂叶，山楂树缺席）

## 三、中文语境自然（v5.2.0 强化 · 07-23 实测）

**每行读起来要像 4 岁小孩跟妈妈指着画面说的话**（主谓/介宾/主系表自然），避免"X 挂树上,Y 挂 X 上"生硬绑定。

### ✅ 自然语序
- "山楂树开出一簇簇小白花"
- "蜜蜂飞进山楂树的花丛里"
- "山楂树的裂叶晒着太阳"
- "山楂树结出一颗颗小青果"
- "山楂树上挂满红灯笼似的红果"
- "夏天来了,石榴树醒啦"（拟人觉醒 → 童趣）

### ❌ 生硬绑定
- "小青柿长出,绿果子柿子树"（语序错乱）
- "苹果树上苹果落"（同词反复）
- "小青梨长成大黄梨"（无主语）

### L3 输出前必须逐行大声朗读自检
（用户原话："别扭/不通顺 = 句式结构问题需重写"）

## 四、旁白精简（v5.2.0 · 07-23 用户原话"旁白文字太多了"实测）

每行中文压到 **5-10 字之间** 为佳，留更多画面空间给生图。

### 精简策略
- 砍掉所有修饰词（"皱瓣""披针""火红""嫩绿""一颗颗"等看画面就行）
- 砍掉重复主语（前后行都已说"X 树"则中间行可省）
- 保留核心动词和领读节奏

### 范例（pomegranate 精简版）
- P3 "石榴树的夏天来啦"（精简但保留"石榴树"做主语）
- P4 "石榴树开红花啦"（主谓宾 + "啦"童趣尾音）
- P5 "蜜蜂飞来了"（隐含主语，画面补全）
- P7 "小青果冒出来了"（萌系动作）
- P8 "红石榴挂满枝"（介宾自然）

## 五、反模板化（v5.2.0 · 07-23 用户原话"旁白有些模板化了请你重新组织语言"实测）

**避免连续多行出现相同句式结构**（如 "X 树开白花 / X 树有绿叶 / X 树长出小青果 / X 树挂满红果" 这种模板化 4 连击）。

### 反模板化策略
1. **每行换句式**：主谓 / 介宾 / 主系表 / 拟人 / 比喻 / 童趣词
2. **每行换主语**：树本身 / 蜜蜂 / 风 / 太阳 / 小孩 / 果实
3. **每行换视角**：客观叙述 / 主观感受 / 拟人觉醒 / 比喻/儿歌韵律
4. **避免 4 连击相同收尾**：如不要 "X 树开 X 花 / X 树有 X 叶 / X 树长 X 果 / X 树挂 X 果"

### ✅ 反模板化范例（hawthorn v3）
- P3 "春天来了，山楂树醒啦"（时序+拟人觉醒）
- P4 "山楂树开出一簇簇小白花"（主谓宾+"一簇簇"叠词领读）
- P5 "蜜蜂飞进山楂树的花丛里"（介宾+具体位置）
- P6 "山楂树的裂叶晒着太阳"（领属+拟人）
- P7 "山楂树结出一颗颗小青果"（主谓宾+叠词）
- P8 "山楂树上挂满红灯笼似的红果"（比喻）

## 六、末句合理性（v5.2.0 · 07-23 banana "结尾不合理"实测）

**末句必须保持"主题物做主语"**，不能突然切换到非主题角色做主语。

### ❌ 不合理（banana P8 原版）
- 英文 `A monkey peels a banana`（猴子做主语）
- 中文 "小猴子剥开香蕉吃"（猴子做主语）
- 问题：猴子变主角，"香蕉树"作为主题物的主语指向丢失

### ✅ 合理（修正版）
- 英文 `The banana tree gives us sweet bananas`（香蕉树做主语）
- 中文 "香蕉树送我们甜甜的香蕉，Banana Tree"（主谓宾指向香蕉树）

### ✅ 备选修法
- "A monkey visits the banana tree / 小猴子来到香蕉树下，Banana Tree"（介宾指向香蕉树）
- "The banana tree waves in the wind / 香蕉树在风里摇啊摇，Banana Tree"（主语=树）

### 触发信号
- 用户说"结尾不合理" → 检查末句主语是否仍为核心词
- 用户说"末句直接生成好" → 默认生成 1 个最佳版（不要 4 候选）

## 八、3 常见反模式 → 修复示例（07-23 实测沉淀）
