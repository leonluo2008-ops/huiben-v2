# I CAN 旁白实测案例

> 本文档为领读旁白结构原则的实测案例，供理解规则参考。
> 规则中不应硬编码本文档的具体内容。

## 问题分析

**问题1：目标词丢失**
- 原中文旁白用"我能"替代目标词 I can，目标词在中文里消失
- 违反领读核心原则：目标词必须在中文里可见

**问题2：结构断裂**
- "我能跑！I can" = 完整中文句子 + 目标词碎片拼接
- 目标词应作为独立触发元素，与中文并列

**问题3：翻译不准确**
- "冲"不是 I can 的正确翻译
- 准确翻译应为"我能"
